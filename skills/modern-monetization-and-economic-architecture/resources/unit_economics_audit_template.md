# Unit Economics Audit Template & Financial Stress-Test

Use this audit template to verify the economic viability of a newly proposed business blueprint.

---

## 2. Venture Capital Stress-Test Gates

Evaluate the concept against the four non-negotiable venture capital hurdles:

| Hurdle Metric | Critical Failure Threshold | Venture Pass Standard | Status (PASS / FAIL) |
| :--- | :--- | :--- | :--- |
| **Gross Margin %** | $< 65\%$ | $\ge 80\%$ | |
| **CAC Payback** | $> 16\text{ months}$ | $\le 12\text{ months}$ | |
| **LTV / CAC** | $< 3.0\times$ | $\ge 4.0\times$ | |
| **Net Revenue Retention** | $< 100\%$ | $\ge 120\%$ | |

If any metric receives a **FAIL**, the economic architecture must be restructured immediately before finalizing the business blueprint.
